# Nulora

Открытые исходники приложений и твиков для джейлбрейка.

- `camera/HorizonCamera` — отдельное приложение камеры: удержание горизонта по датчикам движения, динамический/фиксированный кроп, запись обработанных кадров и звука, просмотр записей. Системная камера не подменяется.
- `ios26/HorizonMotion` — направленное размытие при анимациях UIKit и прокрутке, включая SpringBoard. Настройки: Nulora Motion, сила, рабочий стол, приложения. Это визуальный эффект, а не повышение частоты экрана. Игры, Metal-видео и защищённые поверхности не поддерживаются.
- `ios26/NuloraDock` — отдельный пакет только для iOS 12: пять мест для приложений, полупрозрачная закруглённая панель, настройки радиуса и прозрачности. Другие твики Dock могут конфликтовать.
- `utility` — будущие утилиты.
- `icons` — оригинальные значки Nulora Camera / Motion / Dock в одной теме. Генератор: `node scripts/icons.cjs`.
- `wallpapers` — будущие обои.

Первая цель: iPhone 5s, iOS 12.5.7, Chimera (rootful, `iphoneos-arm`, бинарник arm64).

## Статус

Результат сборки публикуется только после компиляции. Наличие исходников не означает, что пакет уже испытан на устройстве. Расход памяти, нагрев, направление выравнивания основной/фронтальной камеры и совместимость с другими твиками требуют проверки на реальном iPhone.

Камера сохраняет видео локально. Для сохранения в «Фото» есть отдельная кнопка. Твик не пишет снимки на диск и не передаёт их по сети; кратковременные изображения хранятся только в памяти. Эффект можно выключить и изменить его силу в настройках iOS.

## Сборка

Камера: Xcode + iPhoneOS SDK, `ldid`, `dpkg-deb`; `bash camera/HorizonCamera/scripts/package-deb.sh rootful`.

Твик: Theos, iPhoneOS SDK, `gmake -C ios26/HorizonMotion FINALPACKAGE=1 package`.

Workflow в `.github/workflows/build.yml` собирает пакеты в облаке, проверяет их содержимое и готовит APT-репозиторий с категориями Icons, Camera, Utility, Wallpapers, Motion Blur. DEB также доступны в GitHub Releases как запасной сервер при тайм-ауте Pages. Исходное референсное видео, данные телефонов и личные ключи сюда не включаются. GPG-подпись APT Release пока не настроена; HTTPS и открытый исходный код не заменяют проверку кода и испытания пакетов.

После первой установки твиков: закрыть и открыть приложения, вручную выполнить респринг. Пакеты не выполняют его автоматически. Удаление Motion / Dock через Sileo возвращает штатное поведение после ручного респринга. Перед удалением Dock перенесите пятый значок на рабочий стол. Идентификаторы com.theipos.* сохранены для корректного обновления.
